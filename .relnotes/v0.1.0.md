## Première version

- **Mirroring USB** Android vers Windows — branche, clique, joue.
- Contrôle **souris & clavier** : clic = tactile, molette = zoom, texte tapé directement.
- Faible latence, presets qualité, mode sombre.

Pensé pour Dofus Touch : pas un émulateur, pas de macro — le jeu tourne sur ton vrai téléphone.
