## Correctifs

Version de fiabilisation : correctifs de stabilité et de sécurité sur
l'ensemble de l'application.

**Contrôle et affichage**

- Zoom pincé : en Ctrl+molette bas, les deux doigts envoyés au
  téléphone partaient aux bords de l'écran au lieu de converger
- Bascule WiFi→USB : si le téléphone se dégradait en WiFi sans câble
  disponible à cet instant, la bascule n'était plus jamais retentée —
  elle se déclenche dès qu'un jumeau USB apparaît
- Fermeture : une erreur de déconnexion d'un miroir pouvait empêcher
  l'application de se fermer complètement
- Fuites mémoire : les fiches du marketplace et les plugins restaient
  abonnés au service de langue après leur suppression

**AirPlay / iOS**

- Une fois un appareil pairé, son IP restait fiable pour toujours —
  confiance limitée à 2 heures, puis nouvelle vérification
- Course de connexions : une ancienne session pouvait libérer le slot
  d'une nouvelle (deux flux actifs possibles)
- La clé de session et la fenêtre de pairing transitoire étaient
  partagées entre toutes les IP — un pairing pouvait armer la
  confiance d'un autre client, elles sont maintenant liées à l'IP qui
  s'est appairée
- Un bloc chiffré vide pouvait geler le canal de données des deux
  côtés (session vidéo et flux miroir)

**Audio**

- Si l'ouverture du décodeur échouait une fois, aucune nouvelle
  configuration n'était retentée — le son pouvait rester muet jusqu'au
  prochain miroir
- Deux messages du journal (« son indisponible », « son coupé »)
  affichaient leur clé interne au lieu du texte FR/EN

**Plugins et API locale**

- Les données d'un événement inter-plugin étaient évaluées comme du
  code dans le moteur du destinataire — un plugin pouvait exécuter du
  JS dans le contexte d'un autre, c'est maintenant du JSON strict
- Un token d'une autre longueur que l'attendu levait une erreur 500
  au lieu d'un refus 401 propre

## Sous le capot

  remplacée par l'implémentation AirPlay)
- 144 tests unitaires verts, build sans avertissement
