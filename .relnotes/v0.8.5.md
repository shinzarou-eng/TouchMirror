## ⚠️ Mise à jour prioritaire

Cette version fiabilise le canal des mises à jour automatiques :

- **Double canal de vérification** — si l'API GitHub est indisponible ou
  limitée, l'app bascule sur un canal de secours direct qui ne passe pas
  par l'API
- Fini les bandeaux de mise à jour qui n'apparaissent pas ou qui renvoient
  vers le navigateur quand le canal automatique est disponible

**Si tu utilises la version portable** : télécharge le Setup — une fois
installé, toutes les mises à jour suivantes seront automatiques.

**Full Changelog**: https://github.com/shinzarou-eng/TouchMirror/compare/v0.8.4...v0.8.5
