## Nouveautés

- **3 nouveaux plugins officiels** — tous vérifiés, dans le catalogue et livrés dans `plugins/` :
  - 🔇 **Auto-mute** — un seul miroir sonore : l'actif. Ré-applique la règle en continu, y compris quand l'audio démarre après le changement de focus.
  - ✅ **Checklist** — bloc-note éditable sur chaque miroir : `checklist.txt` au bloc-notes, clic sur une ligne pour cocher (le fichier suit), ligne finale pour tout remettre à zéro.
  - ⏱️ **Uptime** — journal de session par miroir : durée de la connexion en cours et nombre de coupures.
- **Almanax v1.1** — calendrier complet embarqué : offrande et bonus du jour affichés sur les miroirs, hors-ligne.

## API plugins

- `tm.mute(slot, bool)` — coupe/remet l'audio **local** d'un miroir (le volume du téléphone n'est pas touché), aussi via `POST /api/mirrors/{slot}/mute/{bool}`. Champ `muted` ajouté à `getMirrors()`.
- **Overlays à lignes cliquables** — `tm.overlay(slot, { lines: [...] })` transforme le widget en panneau texte ; un clic sur une ligne émet l'événement `overlay.line` `{ slot, id, index }`.
- `tm.read` / `tm.write` — fichiers **confinés au dossier du plugin** : extensions data uniquement (`.txt`, `.json`, `.csv`…), pas de code réinscriptible, 256 Ko max. Jamais exposés sur l'API HTTP.

## Corrections

- Un mute demandé avant le premier paquet audio n'est plus perdu (l'état est mémorisé puis appliqué à la création du lecteur, Android et iOS).
