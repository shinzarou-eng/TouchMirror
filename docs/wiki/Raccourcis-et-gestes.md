# Raccourcis et gestes

## Souris sur le miroir

| Geste | Action sur le téléphone |
|---|---|
| Clic gauche | Toucher |
| Clic maintenu + glisser | Glisser / swipe |
| Molette | Défilement vertical |
| `Ctrl` + molette | Pinch-to-zoom (zoom de la map) |
| Clic droit | Retour Android |

## Clavier

| Touche | Action |
|---|---|
| Texte | Saisi directement dans le champ actif — comme un clavier Bluetooth |
| `Entrée` | Valider / envoyer |
| `Retour arrière` | Effacer |
| `Échap` | Retour Android |
| `Ctrl` + `V` | Colle le presse-papiers du PC sur le téléphone |

## Fenêtre

| Raccourci | Action |
|---|---|
| `F11` | Basculer le plein écran |
| Survol du bord haut (en plein écran) | Barre de contrôle : ← retour, ⌂ accueil, ▢ récents, quitter |

## Toolbar

| Bouton | Action |
|---|---|
| 📖 (à gauche) | Panneau d'aide — sites Dofus Touch |
| **Dofus** | Lance le jeu sur le téléphone |
| 📷 | Capture PNG |
| ⏺ | Enregistrement MP4 |
| ↻ | Rotation de l'affichage |
| ⛶ | Plein écran |
| ⏻ | Déconnecter |
| ⋯ | Options : WiFi, mode capture… |

> TouchMirror n'ajoute **aucun raccourci tactile ni macro** — chaque action correspond à un geste humain, conformément aux règles Ankama.
