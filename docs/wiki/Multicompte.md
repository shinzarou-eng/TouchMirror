# Multicompte

Joue plusieurs comptes Dofus Touch en même temps — **un compte par téléphone physique**, dans **une seule fenêtre**. C'est le modèle autorisé par Ankama (pas d'émulateur, pas de duplication logicielle).

## Ajouter un appareil

1. Connecte le premier téléphone normalement
2. Branche le deuxième → il apparaît dans le sélecteur
3. Clique **＋ Ajouter** → une deuxième tuile s'ouvre dans la grille

Répète pour un 3e, un 4e…

## La grille

| Nombre | Disposition |
|---|---|
| 1 | Plein écran |
| 2 | Côte à côte |
| 3–4 | Grille 2×2 |
| 5+ | La grille s'adapte automatiquement |

## Tuile active

- **Clique une tuile** pour la cibler : bordure accentuée = tuile active
- Seule la tuile active reçoit les clics et le clavier
- Seule la tuile active **sort le son** (évite la cacophonie)
- Les autres tuiles continuent de s'afficher en temps réel

## Conseils

- Chaque téléphone = un compte Ankama distinct, connecté à son propre client officiel
- Le WiFi fonctionne en multicompte aussi, mais l'USB est plus stable à 3+ appareils
- Si le PC rame à 4 miroirs, baisse la résolution / le fps dans les **Réglages**
- L'option **Écran éteint** s'applique par appareil — pratique pour économiser plusieurs batteries
