# TouchMirror — Wiki

Bienvenue sur la documentation de **TouchMirror**, le mirroring Android natif pour Windows pensé pour Dofus Touch.

TouchMirror affiche et contrôle ton téléphone Android depuis le PC : tu branches, tu cliques, tu joues. Gratuit, open source, sans compte, sans pub.
